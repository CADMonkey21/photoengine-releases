# PhotoEngine Studio — Authorized Binary Distribution

> **PROPRIETARY & RESTRICTED ACCESS:**  
> PhotoEngine Studio is proprietary software. Release archives hosted in this repository are **AES-256 encrypted (`.7z` with header encryption)** and are **not available for general public use or redistribution**. Extraction requires an explicit passphrase issued directly by the author to authorized recipients.

## Repository Scope & "Source Code" Archives
This repository serves strictly as a binary distribution mirror and contains **zero application source code**:
- All PhotoEngine Go, AutoLISP, and UI source code resides in a separate private repository.
- The automatic `Source code (zip)` and `Source code (tar.gz)` links attached to GitHub Releases are generated by GitHub and contain **only** `README.md`, `LICENSE`, and `KEYS.allowed_signers`.

## Authorized Download & Extraction
1. Install **[7-Zip](https://www.7-zip.org/)** (Windows File Explorer's built-in zip extractor does not support AES-256 header-encrypted `.7z` archives).
2. Download the release archive(s) from the **[Releases](../../releases)** page:
   - **`PhotoEngine_vX.Y.Z.7z`** — Core `PhotoEngine.exe` desktop studio + curated Tier 1 `IES_Favorites.zip` sidecar.
   - **`PhotoEngine_IES_Vault.7z`** *(Optional)* — Tier 2 manufacturer Reference Vault (`IES_Vault.zip`, ~1.5 GB).
3. Right-click `PhotoEngine_vX.Y.Z.7z` -> **7-Zip -> Extract Here** and enter your authorized release passphrase.

## Cryptographic Signature Verification (Ed25519)
Authorized recipients can verify archive integrity and authenticity prior to extraction in PowerShell:

```powershell

Get-FileHash .\PhotoEngine_*.7z -Algorithm SHA256
```
